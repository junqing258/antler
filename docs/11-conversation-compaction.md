# 会话上下文压缩

在会话输入框选择 `/compact`（也可输入 `/压缩` 筛选），再发送命令。后端会用当前模型生成摘要，并将该模型缓存中的历史消息替换为摘要。系统指令、技能与工具声明继续保留，界面的聊天记录不删除。

压缩通过现有 `/api/runs` 和 SSE 通道执行，沿用会话占用锁、超时、取消与脱敏。`/compact` 单独分派，不作为普通问题发送给 Agent。摘要调用使用独立 Agent，不提供工具；只有完整、非空且序列化后比旧上下文更短的摘要才提交。模型失败、取消或摘要无效时，原模型上下文不变。

模型上下文目前保存在服务进程的内存中，并按供应商配置和工作目录隔离。压缩作用于当前模型配置的会话缓存；切换模型或重启服务后没有原缓存时，命令会提示先发送消息。前端持久化的聊天记录不等同于后端模型上下文，此次不改变既有的历史恢复机制。

不新增数据库字段或环境变量。验证覆盖 OpenAI/Anthropic 的摘要替换、后续请求、系统与工具保留、失败与取消回退、空会话校验，以及命令选择和发送。
