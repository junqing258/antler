## 已实施内容

### 基础设施与会话

- 当前依赖组合为 Expo SDK 58、React/React DOM 19.3.0、React Native 0.88.1 和 React Native Web 0.21.4。Web 宿主已升级 React，旧聊天界面保留。
- `packages/chat-core` 包含消息领域类型、DTO 转换、事件 reducer、快照合并、水位与斜杠命令；`packages/client-runtime` 的 `ChatSession` 管理发送、幂等重试、停止、历史分页、运行恢复和订阅。Web 现有界面通过临时 adapter 使用 session。
- `packages/platform` 及 Web/实验性原生适配器注入网络、认证连接、前后台通知、UUID 和流处理等能力。会话变更和 Run SSE 分别维护各自游标。剪贴板、链接等平台能力尚未完整抽取。
- 客户端凭据来源的会话检查本设备 API Key 与绑定协议、端点是否匹配；缺失时保留历史查看和运行恢复，阻止发送并提示配置。该逻辑已有自动化覆盖，真实跨设备行为仍需验证。
- 实验性移动入口使用 AsyncStorage 保存普通配置、SecureStore 保存令牌及模型 Key；需要手动提供访问令牌，尚无完整登录、自动刷新或退出流程。Web 诊断入口使用浏览器存储，不等同于原生安全存储。

### 共享聊天界面

- `packages/ui` 已提供消息气泡、列表和输入框，供实验性移动聊天入口使用；Web 主聊天尚未切换。消息气泡显示文本、思考内容、工具调用、错误及未知类型占位，尚不等同于完整的思考/工具交互组件。
- Markdown 使用 `markdown-it` 和 RN/RNW 渲染，覆盖常见段落、强调、列表、引用、代码块、表格和 HTTP(S)/邮件链接；原始 HTML 作为文本处理，图片暂显示替代文字。语法高亮、脚注、中文强调增强、流式补全及设备表现仍待验证或实现。
- 列表按平台分流：Web 实现底部跟随和历史前插锚点，原生使用 FlatList 可见位置保持与底部跟随。组件测试覆盖部分 Web 行为，长列表、折叠内容、软键盘和原生设备尚未完成验收。
- Web 输入框支持 Enter 发送、Shift+Enter 换行、输入法组合保护和自增长；共享命令定义已接入 Web 键盘选择及原生触摸菜单。原生输入法、焦点、触摸和键盘避让需设备实测。

## 已验证与未验证

- 最近一次完整检查：`pnpm check`、`pnpm test` 通过；其中 Web 测试 138 项、后端 367 项。`pnpm build` 已生成 Web、后端和 Expo iOS/Android/Web bundle；之后输入框 Web 选项滚动的微调通过了共享 UI 类型检查和相关组件测试。测试和 bundle 导出不等于设备运行。
- Docker 镜像曾使用冻结 lockfile 构建，并以隔离 PostgreSQL 验证 Web 静态页面、401、鉴权会话 API 和会话变更 SSE 心跳；未运行真实模型。后续共享 UI 改动需在下一个交付检查点重新验证镜像。
- 已构建 iOS 模拟器 Debug 应用，但模拟器安装因本机高负载中止，未验证启动。Android 原生构建未完成，本机此前缺少项目所需 SDK。
- 浏览器曾以隔离假后端验证实验聊天的发送与中文流式回复；还验证了输入框高度、Enter 发送和命令填充。最近截图采集超时，不能把这些结果作为完整视觉或响应式验收。长列表浏览器检查也尚未形成有效验收结果。
- 后端并发 Skill 测试曾出现临时目录 `ENOENT`；已修复工作区扫描与临时目录重命名的竞争，相关测试、全量测试及后端构建随后通过。

## iOS 真机调试现状

**目前还没有完成真机安装或运行验证。** 已有实验性 Expo 入口和一次 iOS 模拟器 Debug 构建结果，不能据此保证真机可用。继续推进需准备可用的 Xcode 签名团队与设备、设备信任和开发者模式，并根据项目配置生成并安装开发构建；连接开发电脑时使用手机可访问的地址，而不是手机上的 `127.0.0.1`。测试需要可用的后端和相应认证/模型配置；涉及发布验收时必须使用目标 HTTPS 后端。

真机开发构建、Expo Go 或 JavaScript bundle 导出均不能替代 iOS/Android 独立 Release 安装包的鉴权 API、SSE、断线重连和前后台恢复验收。实际设备、签名及后端可用性需在执行时确认，不在本文假定已具备。

## 后续实施顺序

1. **完成设备基线与 P0 缺口。** 准备 iOS 真机开发构建并验证安装、启动、配置、鉴权 API、中文增量 SSE、取消和前后台恢复；配置 Android 构建环境并执行同类检查。单列双平台独立 Release 与 HTTPS 验收，记录 ATS/明文配置和结果。
2. **完成 P2 组件与平台能力。** 补齐剪贴板和链接等平台边界、认证与 token 刷新；建立固定 Markdown/长会话样例，验证选择、链接、表格、代码、流式渲染和性能；在设备上验证列表锚点、菜单、输入法、键盘避让与无障碍。补齐尚缺的 Markdown 和消息展示能力，修复验证中发现的问题。
3. **完成 P3 聊天迁移。** 实现完整共享 ChatScreen、思考和工具展示、模型选择、等待/错误/空态及分页；通过开发开关比较新旧视图并回归会话语义。达到方案验收后切换 Web 默认界面，删除旧 adapter、assistant-ui 依赖及相关样式和测试 mock。
4. **逐域完成 P4。** 依次迁移会话导航、认证、设置、Agent、Skill 和定时任务；每域完成桌面与窄屏视觉、键盘焦点、无障碍和行为回归后清理旧实现。
5. **完成 P5 发布验收。** 完整实现原生导航与配置恢复，测试登录刷新/退出、跨账号隔离、弱网和前后台恢复；以真实 HTTPS 后端和双平台 Release 安装包验证同账号续聊、生成中切端及服务端/客户端两类凭据场景。

每个实现阶段继续运行 `pnpm check`、`pnpm test` 和受影响的构建；界面变更增加实际页面和响应式视觉核查，原生功能增加设备验证。涉及共享 workspace 依赖或镜像的变更重新执行 Docker 构建和 API/SSE 冒烟。任何测试失败、跳过项或未覆盖的平台应单独记录，不将其标记为通过。
