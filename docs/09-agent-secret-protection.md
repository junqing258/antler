# Agent 环境变量防护

Agent 默认禁止读取、写入和编辑 `.env`、`.env.*`、`.env-*`（包括示例文件）以及 `rag-config.json`。工作区工具和 Skill 资源工具同时检查请求路径与符号链接解析后的路径；bash 拒绝直接引用这些文件的命令。

`SecretGuard` 在运行开始与工具执行前由宿主内部检查后端 `.env` 和工作区环境文件，仅把 key、token、secret、password、pass、数据库连接串等凭据字段的值加入脱敏集合，同时保护完整环境文件及其编码形式。采样比例、端口、SMTP 地址、认证模式及其他普通配置值不加入敏感词集合，不依赖配置白名单。宿主检查不会把文件内容交给 Agent。bash 执行后再次检查环境文件，已轮换或删除的旧值在当前 adapter 生命周期内仍保持脱敏。工作区扫描不进入 `.git`、`.codegraph`、`node_modules`、`dist`、`target`，也不递归符号链接目录。环境文件超过 256 KiB 或无法读取时，工具/运行失败，不返回文件内容。

bash 不读取 shell 启动文件，并移除继承环境中的后端 `.env` 变量和敏感变量。显式提供给工具的 Skill 环境变量仍可使用，例如 RAG URL 和 API Key；模型只可收到脱敏后的输出。工具输出、错误中的已知凭据值会替换为 `[REDACTED]`，同时覆盖其 Base64、十六进制、URL 编码和 JSON 转义形式，以及完整环境文件的常见编码形式。先脱敏，再截断输出。

用户消息原样传给模型，后续轮次不改写已有用户消息；标题和压缩摘要的输入也不再进行全局值替换。系统/技能提示中的已知凭据，以及生成的标题和摘要仍按输出边界脱敏。用户主动输入的内容可能会发送给所选模型供应商。

宿主通过 `config/tool-environment.ts` 的明确允许列表向 bash 注入股票和 COS 技能配置：`TUSHARE_TOKEN`、`TAVILY_API_KEY`、`SERPAPI_KEY`、`COS_SECRET_ID`、`COS_SECRET_KEY`、`COS_TOKEN`，以及 `COS_REGION`、`COS_BUCKET`、`COS_APP_ID`、`COS_SCHEME`、`COS_ENDPOINT`。RAG 配置继续使用当前有效设置。上述配置来自 backend 进程环境（部署时可由 `.env.deploy` 传入）；工作区 `.env` 不会自动加载成工具环境。允许列表适用于所有 Agent 的 bash 工具，不按 Agent 隔离。模型、SMTP、数据库、Redis 和服务访问凭据继续由对应的宿主组件使用，不向 bash 开放。

会话事件在存入内存、数据库和推送 SSE 前脱敏，覆盖工具参数、工具结果、模型文本、思考文本和错误消息。模型分段输出保留可能属于敏感值的末尾片段，待后续 chunk 匹配后替换；运行结束或中断时仍未完成的敏感前缀也会被替换。协议字段和运行标识保持可用。知识检索快照也在写入数据库前脱敏。

这是应用层纵深防护，不能作为任意代码执行的隔离边界。保留 bash 时，脚本仍可能读取工作区外的文件、扫描排除目录或通过自定义变换、分段打印、网络请求绕过已知值匹配；需要抵御恶意 Agent 时，应在独立容器/操作系统沙箱中执行命令，仅向受信任工具提供必要凭据。真正的短凭据仍可能使工具输出或对外事件中的普通文本被额外脱敏，但不会改写发给模型的用户消息。自定义凭据应使用含 `SECRET`、`TOKEN`、`KEY`、`PASSWORD` 等明确标识的变量名；普通名称的单独值不会自动参与脱敏。

防护适用于新增 Agent 输出和事件，不自动清理既有会话、数据库记录、用户原始输入或磁盘文件。不需要新增环境变量或数据库迁移。
