# Agent 环境变量防护

Agent 默认禁止读取、写入和编辑 `.env`、`.env.*`、`.env-*`（包括示例文件）以及 `rag-config.json`。工作区工具和 Skill 资源工具同时检查请求路径与符号链接解析后的路径；bash 拒绝直接引用这些文件的命令。

`SecretGuard` 在运行开始与工具执行前收集后端 `.env`、工作区内环境文件的内容和值，以及环境变量名称包含 key、token、secret、password、auth 等敏感标识的值。bash 执行后再次检查环境文件，已轮换或删除的旧值在当前 adapter 生命周期内仍保持脱敏。工作区扫描不进入 `.git`、`.codegraph`、`node_modules`、`dist`、`target`，也不递归符号链接目录。环境文件超过 256 KiB 或无法读取时，工具/运行失败，不返回文件内容。

bash 不读取 shell 启动文件，并移除继承环境中的后端 `.env` 变量和敏感变量。显式提供给工具的 Skill 环境变量仍可使用，例如 RAG URL 和 API Key；模型只可收到脱敏后的输出。工具输出、错误、模型输入中的已知敏感值会替换为 `[REDACTED]`，同时覆盖其 Base64、十六进制、URL 编码和 JSON 转义形式，以及完整环境文件的常见编码形式。先脱敏，再截断输出。

会话事件在存入内存、数据库和推送 SSE 前脱敏，覆盖工具参数、工具结果、模型文本、思考文本和错误消息。模型分段输出保留可能属于敏感值的末尾片段，待后续 chunk 匹配后替换；运行结束或中断时仍未完成的敏感前缀也会被替换。协议字段和运行标识保持可用。知识检索快照也在写入数据库前脱敏。

这是应用层纵深防护，不能作为任意代码执行的隔离边界。保留 bash 时，脚本仍可能读取工作区外的文件、扫描排除目录或通过自定义变换、分段打印、网络请求绕过已知值匹配；需要抵御恶意 Agent 时，应在独立容器/操作系统沙箱中执行命令，仅向受信任工具提供必要凭据。短值或常见配置值可能使普通文本被额外脱敏。

防护适用于新增 Agent 输出和事件，不自动清理既有会话、数据库记录、用户原始输入或磁盘文件。不需要新增环境变量或数据库迁移。
