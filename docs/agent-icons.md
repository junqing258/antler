# Agent 图标

前端复用已有 `lucide-react`，以固定的 24 个图标作为候选。

新建 Agent 或修改名称、描述后保存时，自动调用 `POST /api/agents/icon` 选择图标；编辑页也支持手动重新生成并预览。仅修改提示词、技能或工作目录时保留已有图标。

生成请求优先使用设置中的供应商、模型、Base URL 和凭据；未配置客户端凭据时使用服务端模型配置。模型独立运行，不携带会话或工具，图标名称经过白名单校验。生成失败不阻断保存，保留当前图标。

图标保存在 `agents.icon`，列表和编辑页使用同一组件展示；旧 Agent 或未知图标显示默认机器人。图标修改不会改变 Agent 的聊天上下文指纹。

部署前运行 `pnpm --filter @antler/server db:deploy`，应用 `20261023010000_agent_icon` 迁移。本次没有新增环境变量。
